OVERVIEW
--------
This is a 4x HD texture replacement package for the GameCube release of 
"Skies of Arcadia Legends" (Title ID: GEA), designed for Dolphin Emulator.

Version 0.3.0 completes 100% coverage of all 31,010 textures extracted 
directly from the game disc's internal archives (.mld and .mlk).

All textures have been converted from the master 28.04 GB PNG library into 
Microsoft DirectX BC7 DDS format with full hardware mipmaps (-m 0). Using 
BC7 DDS bypasses CPU runtime decoding overhead and allows textures to load 
directly into GPU VRAM using Dolphin's texture prefetching, eliminating 
frame-time spikes and micro-stuttering during gameplay.


CHANGELOG - VERSION 0.3.0
-------------------------
1. Complete ISO Archive Coverage (31,010 Textures)
   - Full 4x upscale and manual curation across all game files dumped directly 
     from the raw GameCube disc image.
   - Complete coverage across all 8 modular packages: Characters & Enemies, 
     Towns & Ports, Dungeons & Ruins, Ships & Ship Battles, Overworld, Battle 
     Stages & Effects, UI, and Cutscenes & Ending.

2. Alpha Channel & Ghost Haze Audit
   - Audited all 30,000+ textures using custom analysis tooling to identify 
     and eliminate low-alpha edge fringing (1 <= alpha <= 25).
   - Removed gray border artifacts from cutouts, character geometry, and foliage.

3. Atmospheric FX Processing Standard
   - Implemented a standardized pipeline for transparent atmospheric overlays 
     (smoke, clouds, mist, fog, and heat haze): 4x upscale with proportional 
     Gaussian blur applied strictly to the alpha channel.
   - Eliminates pixel stair-stepping on transparent textures while preserving 
     gradient density.

4. Scene & Texture Corrections
   - Mid-Ocean Rhaknam Cutscene (205ab01): Resolved white fog overlay bug 
     that caused full screen occlusion; restored correct alpha density.
   - Temple of Pyrynn Area 2 (109c): Removed 7 solid-opaque (alpha = 255) 
     textures that caused cross-folder hash collisions and white screen washouts.
   - Galcian Cutscenes & Battles: Corrected eye and cape alpha masks; removed 
     bounding box fringing.
   - Foliage & Crystals: Repaired over-sharpened alpha cutouts on Aika's room 
     plant (002ab) and Shrine Island activation crystal (103a).
   - Delphinus Bridge Flag Shadow (034ab): Standardized to a single canonical 
     103-level alpha gradient and purged redundant duplicate files.

5. Runtime GPU Palettes & Dolphin Compatibility
   - Extracted and remastered dynamic Format 8 (C4, 4-bit paletted) runtime 
     textures generated by the GameCube GPU during the final boss battles, 
     ship combat, and Intro Movie A.
   - Generated cross-compatibility aliases for both standard .dds and modern 
     Dolphin _arb.dds naming schemes to ensure reliable hash matching.

INSTALLATION INSTRUCTIONS
-------------------------
1. Download & Extract:
   - Download the desired .7z packages from GitHub Releases.
   - Extract the archive(s) using 7-Zip. All archives output into a "GEA" folder.

2. Move to Dolphin Directory:
   Place the "GEA" folder into Dolphin's texture load path:
   - Windows: Documents\Dolphin Emulator\Load\Textures\
   - macOS: ~/Library/Application Support/Dolphin/Load/Textures/
   - Linux: ~/.local/share/dolphin-emu/Load/Textures/

   Structure:
   Load/Textures/GEA/
     ├── 01 - Characters & Enemies/
     ├── 02 - Towns & Ports/
     ├── 03 - Dungeons & Ruins/
     ├── 04 - Ships & Ship Battles/
     ├── 05 - Overworld/
     ├── 06 - Battle Arenas & Effects/
     ├── 07 - UI, Menus & Fonts/
     └── 08 - Cutscenes & Ending/

3. Configure Dolphin Settings:
   - Graphics -> Advanced tab:
     - Enable "Load Custom Textures"
     - Enable "Prefetch Custom Textures" (Recommended: preloads DDS into VRAM)
   - Graphics -> General tab:
     - Backend: Vulkan or Direct3D 12 recommended
   - Graphics -> Enhancements tab:
     - Internal Resolution: 3x (1080p), 4x (1440p), or 5x (4K)
     - Anisotropic Filtering: 8x or 16x
     - Arbitrary Mipmap Detection: Enabled
